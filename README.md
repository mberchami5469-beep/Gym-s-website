# 🥊 Berchami Academy – Responsive Boxing Website

A modern and responsive website developed for **Berchami Academy**, a boxing academy. This project was created as part of a Bootstrap practical assignment (TP) to practice front-end web development.

The website presents the academy, its training programs, available services, and contact information through a clean and modern design.

## 📸 Project Overview

**Berchami Academy** is a boxing-themed website designed with a black, red, and white color palette to reflect the identity and energy of combat sports.

### 🌐 Website Pages

The website contains four main pages:

- **Home:** Introduction to the academy with a hero section and a call-to-action button.
- **About:** Presentation of the academy and its training programs.
- **Services:** Display of six training services using Bootstrap cards.
- **Contact:** Contact form with input validation using JavaScript.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices.
- Navigation bar with a responsive mobile menu.
- Modern layout using Bootstrap Grid System.
- Service cards with hover animations.
- Contact form with JavaScript validation.
- Privacy policy checkbox validation.
- Success and error messages.
- Custom styling with CSS3.

## ⚙️ Installation and Usage

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd Berchami-Academy
```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code.

## 📱 Responsive Design

The website uses Bootstrap responsive classes and CSS media queries to adapt its layout to different screen sizes.

- Desktop: Full navigation and multi-column layouts.
- Tablet: Adapted content and spacing.
- Mobile: Responsive navigation and stacked content.

## 📩 Contact Form

The contact form uses JavaScript to validate:

- Name field.
- Email field.
- Message field.
- Privacy policy checkbox.

**Note:** The form performs client-side validation only. It does not send messages to a backend server.
